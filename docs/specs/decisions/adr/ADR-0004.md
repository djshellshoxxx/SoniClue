# ADR-0004: Initial devices and sensor bridge

Date: 2026-10-12. Status per decision below.

## DEC-004: Initial interfaces & sensors

* **Question:** Which devices are targeted first?
* **Status:** VALIDATION_REQUIRED
* **Decision:** Class-compliant USB interfaces; USB/XLR measurement mics; piezo contact pickups; IEPE accelerometer via conditioner; laptop mic (tier 1)
* **Rationale:** Affordable and common
* **Rejected alternatives:** -
* **Sources:** spec 18 §3
* **Owner → resolution method → required evidence → dependent tasks → exit criterion:** owner (hardware) → HQ-02/04/06/07 on each → qualification records → TASK-022..025 → matrix rows QUALIFIED
* **Revisit when:** new device requests

## DEC-004b: Sensor bridge hardware

* **Question:** Which MEMS bridge board/firmware?
* **Status:** BLOCKED
* **Decision:** Protocol v1 + host decoder implemented; board not chosen
* **Rationale:** Hardware selection needs bench evaluation
* **Rejected alternatives:** -
* **Sources:** spec 06 §6
* **Owner → resolution method → required evidence → dependent tasks → exit criterion:** owner (hardware) → bounded feasibility task: compare 2-3 boards (USB CDC rate/noise/cost) → bench report → TASK-026 → one board selected and firmware passes the spec 06 §6 acceptance tests
* **Revisit when:** -
