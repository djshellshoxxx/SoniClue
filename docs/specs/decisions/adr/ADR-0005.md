# ADR-0005: Acquisition modes

Date: 2026-10-12. Status per decision below.

## DEC-005: Acquisition modes & channel counts

* **Question:** Which modes?
* **Status:** SELECTED_DEFAULT
* **Decision:** Timed free-run capture 1-64 ch single device; stimulus-during-capture; file import; bridge dump import; offline two-device alignment; simultaneous multi-device capture deferred
* **Rationale:** Honest about independent clocks; minimal complexity
* **Rejected alternatives:** live multi-device session (clock complexity)
* **Sources:** spec 05
* **Revisit when:** user demand
