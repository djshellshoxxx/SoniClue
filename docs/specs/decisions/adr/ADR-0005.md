# ADR-0005: Acquisition modes

Date: 2026-10-12. Status per decision below.

## DEC-005: Acquisition modes & channel counts

* **Question:** Which modes?
* **Status:** SELECTED_DEFAULT
* **Decision:** Timed free-run capture 1-64 ch single device; stimulus-during-capture; file import; bridge dump import; offline alignment; coordinated simultaneous capture on two or more devices through the app service and CLI (`capture-multi`)
* **Rationale:** Keep independent clock domains explicit and estimate mappings from a shared reference after capture.
* **Rejected alternatives:** treating independent device clocks as synchronized without estimating and validating their mapping
* **Sources:** spec 05
* **Revisit when:** user demand
