# ADR-0014: Missing-value policy

Date: 2026-10-12. Status per decision below.

## DEC-014: Null/unavailable/invalid policy

* **Question:** How are missing values represented?
* **Status:** SELECTED_DEFAULT
* **Decision:** Optional fields omitted (null treated as absent); TaggedValue for measured values
* **Rationale:** One uniform rule; pydantic-native
* **Rejected alternatives:** forbid null entirely
* **Sources:** spec 04 §2
* **Revisit when:** -
