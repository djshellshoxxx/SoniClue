# ADR-0006: Storage formats

Date: 2026-10-12. Status per decision below.

## DEC-006: File formats & schema versions

* **Question:** Which formats?
* **Status:** SELECTED_DEFAULT
* **Decision:** float32 WAV chunks (10 s; RF64 >4 GB) + SQLite JSON documents + npz derived + zip .scarchive; schema 1.0.0 semver; store v1
* **Rationale:** Lossless; transparent; transactional
* **Rejected alternatives:** HDF5; FLAC for raw (float not supported)
* **Sources:** spec 13
* **Revisit when:** format limitation found
