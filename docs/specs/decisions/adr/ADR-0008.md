# ADR-0008: Numerical defaults

Date: 2026-10-12. Status per decision below.

## DEC-008: Numerical defaults & thresholds

* **Question:** Which defaults?
* **Status:** VALIDATION_REQUIRED
* **Decision:** Hann; 1 Hz target; 50% overlap; >=8 independent averages; tone prominence 10 dB (evidence 15 dB); coherence alpha 0.05 & practical 0.5; min effect 1 dB; estimated floor 0.5 dB; clip 0.999; silence -140 dBFS; low -80 dBFS; DC 0.01; airborne 6/3 dB; gradient 6 dB; sync budget 0.35 rad; ambiguity 0.8
* **Rationale:** Engineering defaults; conservative
* **Rejected alternatives:** -
* **Sources:** spec 08/09
* **Owner → resolution method → required evidence → dependent tasks → exit criterion:** diagnostics owner → held-out real-world evaluation (spec 17 §6) → confusion/abstention report → TASK-040 → thresholds frozen on tuning set and evaluated on held-out set
* **Revisit when:** evaluation results
