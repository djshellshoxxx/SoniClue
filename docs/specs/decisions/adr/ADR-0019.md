## DEC-019: Report rendering

* **Question:** How are reports rendered?
* **Status:** SELECTED_DEFAULT
* **Decision:** Headless matplotlib figures; reportlab PDF; self-contained HTML
* **Rationale:** Reports independent of the GUI
* **Rejected alternatives:** Qt printing
