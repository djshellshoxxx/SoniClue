# ADR-0007: Calibration conventions

Date: 2026-10-12. Status per decision below.

## DEC-007: Calibration formats & conventions

* **Question:** Which conventions?
* **Status:** SELECTED_DEFAULT
* **Decision:** FS/unit sensitivity; physical = FS/sensitivity; correction dB to ADD; declared response vs correction files; k=2 uncertainty; 0.1 dB gain tolerance; validity band
* **Rationale:** Removes sign ambiguity; testable
* **Rejected alternatives:** dBFS-at-94 dB offsets only
* **Sources:** spec 06 §2
* **Revisit when:** vendor format issues
