# ADR-0002: Platforms and hardware targets

Date: 2026-10-12. Status per decision below.

## DEC-001: OS versions & CPU architectures

* **Question:** Which OS/arch are supported?
* **Status:** SELECTED_DEFAULT
* **Decision:** Windows 11 x64 (primary; Windows 10 22H2 best-effort/UNQUALIFIED); Ubuntu 22.04/24.04 x86-64 (glibc>=2.35) X11/Wayland via Qt; audio stacks WASAPI/MME/DS/WDM-KS and ALSA/JACK/PipeWire-ALSA; ARM64 out of scope
* **Rationale:** Owner asked Windows x64 first then Linux x64; Windows 10 is past end of support
* **Rejected alternatives:** macOS (not requested); ARM64 (no target hardware)
* **Sources:** master prompt §2
* **Revisit when:** new OS release

## DEC-002: Minimum and reference hardware

* **Question:** What hardware is supported/measured?
* **Status:** VALIDATION_REQUIRED
* **Decision:** Minimum: 2-core x64 2015+ / 4 GB / 1366x768 / no GPU; reference machine: owner-designated Windows 11 4-core 8 GB SSD desktop
* **Rationale:** Ordinary desktops per master prompt §17
* **Rejected alternatives:** -
* **Sources:** master prompt §17
* **Owner → resolution method → required evidence → dependent tasks → exit criterion:** owner → owner names a reference machine; run tools/benchmark.py and HQ-03 → benchmark JSON + HQ-03 log → TASK-021 → budgets in spec 16 met on the reference machine
* **Revisit when:** hardware change
