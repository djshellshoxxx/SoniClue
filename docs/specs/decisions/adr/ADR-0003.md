# ADR-0003: Python + SciPy + PortAudio stack

Date: 2026-10-12. Status per decision below.

## DEC-003: Dependency versions & toolchain

* **Question:** Which runtime/toolchain?
* **Status:** SELECTED_DEFAULT
* **Decision:** CPython 3.11; pins in requirements.lock; PyInstaller 6.22.3; no compiler needed (wheels only)
* **Rationale:** Mature scientific stack; no native code justified by profiling
* **Rejected alternatives:** C++/Rust/Electron (see spec 03)
* **Sources:** spec 03
* **Revisit when:** security advisory or EOL

## DEC-003a: ASIO support

* **Question:** Ship ASIO?
* **Status:** BLOCKED
* **Decision:** Not shipped
* **Rationale:** Steinberg SDK licence restricts redistribution
* **Rejected alternatives:** -
* **Sources:** SRC-13
* **Owner → resolution method → required evidence → dependent tasks → exit criterion:** owner → obtain Steinberg licence agreement or use a licence-clean ASIO host → signed agreement → TASK-030 → agreement in place
* **Revisit when:** -
