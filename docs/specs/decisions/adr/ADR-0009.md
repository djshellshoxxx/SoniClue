# ADR-0009: Packaging, signing, licence, updates

Date: 2026-10-12. Status per decision below.

## DEC-009: Packaging & distribution

* **Question:** How to package?
* **Status:** SELECTED_DEFAULT
* **Decision:** PyInstaller onedir; Windows portable ZIP; Linux tar.gz; SHA256SUMS; SBOM; notices; no auto-update
* **Rationale:** Per-user offline install; LGPL-friendly
* **Rejected alternatives:** onefile (LGPL relinking); MSIX (signing)
* **Sources:** spec 19
* **Revisit when:** -

## DEC-009a: Code signing

* **Question:** Sign Windows builds?
* **Status:** BLOCKED
* **Decision:** Unsigned
* **Rationale:** No certificate available
* **Rejected alternatives:** -
* **Sources:** -
* **Owner → resolution method → required evidence → dependent tasks → exit criterion:** owner → acquire certificate; add signing step in CI → signed build verified with signtool → TASK-032 → signed artifacts
* **Revisit when:** -

## DEC-009b: Project licence

## DEC-018: Updates

* **Question:** Auto-update?
* **Status:** SELECTED_DEFAULT
* **Decision:** No updater in 0.1; manual download with checksums
* **Rationale:** Secure update needs signing infrastructure
* **Rejected alternatives:** unsigned updater
* **Sources:** spec 15 §4
